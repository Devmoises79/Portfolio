# 🧑‍💻 Portfólio Pessoal – Moisés Aniceto

Este é o repositório do meu portfólio profissional como desenvolvedor, onde compartilho meus projetos, habilidades e experiências. A proposta é apresentar de forma visual e acessível minhas competências em desenvolvimento web, back-end e outras áreas da tecnologia.

🔗 Acesse o portfólio online:  
👉 https://portfolio-ten-delta-43.vercel.app/index.html

---

## ✨ Tecnologias Utilizadas

- **HTML5**
- **CSS3**
- **JavaScript**
- **Vercel** (deploy)

---

## 📁 Estrutura

``` bash
- `index.html` – Página inicial com informações de perfil e redes.
- `projetos.html` – Galeria dos principais projetos com links e descrições.
- `contato.html` – Formulário para contato direto.
- `style.css` – Estilo global do site.
- `scripts.js` – Futuras funcionalidades e interações da interface.
```
---

## 📌 Principais Funcionalidades

- Interface responsiva
- Links diretos para repositórios dos projetos
- Página de contato com formulário funcional
- Organização clara das seções (home, projetos, contato)
